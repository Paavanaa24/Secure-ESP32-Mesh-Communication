# 🚀 Secure ESP32 Mesh Communication System

A secure infrastructure-free wireless communication system developed using **ESP32**, **ESP-NOW**, and **Bluetooth Classic**. The project enables peer-to-peer communication without relying on Wi-Fi or cellular networks, making it suitable for emergency communication, disaster response, and remote environments.

---

## 📖 Overview

Traditional communication systems depend heavily on internet connectivity or cellular infrastructure. During emergencies or natural disasters, these services may become unavailable.

This project creates a decentralized mesh communication system where ESP32 devices communicate directly using ESP-NOW while supporting Bluetooth connectivity for mobile devices.

---

## ✨ Features

- 📡 Infrastructure-free communication
- 🔒 AES-128 encrypted messaging
- 📲 Bluetooth Classic support
- 📶 ESP-NOW peer-to-peer communication
- 🚨 Emergency SOS messaging
- 👥 Multi-node communication
- ⚡ Low latency communication
- 🔋 Low power consumption
